# app/src/components/ — reusable building blocks

Pieces of UI used by the screens. No network calls here.

- `TryOnSheet.tsx` — the try-on sheet: tips, loading, result, errors
- `AppHeader.tsx`, `BottomNav.tsx` — the purple top bar and the tab bar
- `ImageCarousel.tsx`, `PhotoViewer.tsx` — product photos, swipe and full screen
- `SizeOptions.tsx`, `RelatedProducts.tsx` — size chips and the related row
- `PhoneFrame.tsx` — keeps the web version phone-sized on a laptop
