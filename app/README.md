# app/ — the iPhone app

React Native + Expo SDK 58. Runs in Expo Go (iPhone), the iPhone Simulator, and Safari (web build).

- `src/` — all app code (screens, components, try-on logic)
- `assets/` — icons and product photos shown in the app
- `.env.example` — settings; copy to `.env` (already points at the live server)

Run: `npm install`, `cp .env.example .env`, `npx expo start`, then scan the QR code with Expo Go.
